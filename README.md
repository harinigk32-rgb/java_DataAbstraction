Java Data Abstraction - Hotel Booking System

About the Project

This is a beginner-level Java project demonstrating the concept of Abstraction using a Hotel Booking System scenario.

The program represents different hotel room booking types, such as Suite and Deluxe, using an abstract parent class.

Concepts Covered

Abstraction

Abstract Classes

Abstract Methods

Inheritance (extends)

Method Overriding (@Override)

super keyword

Object Creation

Project Scenario

The application simulates a hotel booking process.

HotelBooking acts as the abstract parent class.

SuiteBooking represents suite room bookings.

DeluxeBooking represents deluxe room bookings.

Each child class provides its own booking confirmation implementation.

Technologies Used

Java

IntelliJ IDEA

Sample Output

The program displays:

Hotel welcome message

Room-specific welcome message

Booking confirmation message

Through this project, I learned how abstraction hides implementation details and exposes essential functionality. I also practised inheritance and method overriding in Java.
